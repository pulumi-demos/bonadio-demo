# Azure App Service (C#)

A Pulumi C# program that deploys a Linux Azure App Service using the `azure-appservice` component from the organization's private registry.

## What it deploys

The program creates one `AppService` component (`web`), which in turn creates:

- An Azure resource group
- A Linux App Service plan
- A Linux web app with HTTPS only, TLS 1.2+, FTPS disabled, HTTP/2 and a system-assigned managed identity

Every resource is tagged with the Pulumi project and stack names, and the web app gets an `ENVIRONMENT` app setting set to the stack name. Resource names are auto-generated by Pulumi.

## Prerequisites

- Azure credentials available to the `azure-native` provider. In this organization, link an ESC environment that provides them, for example `pulumi config env add cloud-access/azure-oidc`.
- .NET 10 SDK.
- Run `pulumi install` after creating the project. This generates the `azure-appservice` SDK from the registry package declared in `Pulumi.yaml`.

## Configuration (inputs)

| Key | Default | Description |
|---|---|---|
| `azure-native:location` | `eastus` | Azure region to deploy to. |
| `skuName` | `B1` | App Service plan SKU name, for example `B1`, `S1`, `P1v3`. |
| `skuTier` | `Basic` | App Service plan SKU tier matching the SKU name, for example `Basic`, `Standard`, `PremiumV3`. |
| `linuxFxVersion` | `DOTNETCORE\|10.0` | Linux runtime stack, for example `DOTNETCORE\|10.0` or `NODE\|22-lts`. |

Set values with `pulumi config set <key> <value>`.

## Stack outputs

| Output | Description |
|---|---|
| `resourceGroupName` | Name of the resource group containing the app. |
| `appName` | Name of the web app. |
| `url` | HTTPS URL of the web app. |

## Usage

```bash
pulumi new azure-appservice-csharp
pulumi config env add cloud-access/azure-oidc
pulumi config set skuName S1
pulumi config set skuTier Standard
pulumi up
pulumi stack output url
```

The app starts with the default App Service page. Deploy your application code to the web app separately.

## Clean up

```bash
pulumi destroy
```
